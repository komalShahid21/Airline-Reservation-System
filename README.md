# ✈️ Airline Reservation System

## 📌 Description
A comprehensive Python-based console application designed to simulate an airline reservation system. It handles user authentication, flight searching, booking, and cancellation processes.

## 🛠️ Technologies Used
*   Python 3
*   Jupyter Notebook
*   File Handling (for persistent data storage)

## ✨ Key Features
*   **User Authentication:** Secure registration and login system with email validation.
*   **Profile Management:** Users can manage their personal details with strict input validation (Date of Birth, Passport Number, Phone Number).
*   **Flight Listing & Status:** Displays featured destinations with ticket prices and provides random flight status updates (On Time, Delayed, Cancelled).
*   **Booking System:** Allows users to select departure/arrival cities, choose class (Economy, Business, First), and book tickets for multiple passengers.
*   **Payment & Cancellation:** Simulates payment methods (Card/Office) and provides a refund request feature.

## 🚀 How to Run
1. Clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Run the cells sequentially to interact with the system.
